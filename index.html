📖 What Is Obsidian-LLM-Plugin?

Obsidian-LLM-Plugin is a powerful add-on for Obsidian, the popular note-taking application. It brings large language models (LLMs) directly into your notes. Whether you prefer a local model for privacy or a web-based model for advanced capabilities, this plugin gives you several easy ways to chat with AI. You can open a chat in a modal window, use a floating widget, access a FAB (floating action button) window, or run commands directly. No programming knowledge is needed—just a few clicks and you are ready to go.

The plugin is designed for everyday users. It removes the complexity of setting up AI tools and lets you focus on your notes. Whether you want to brainstorm ideas, summarize text, or translate content, the AI is always one click away inside Obsidian.

✨ Key Features

💬 Multiple Chat Interfaces Choose the way you like to chat: a modal window, a floating widget, a FAB window, or simple commands. Each interface is designed for different workflows.
🌐 Local and Web-Based Models Connect to local LLMs (like Ollama) for offline use, or web-based models (like OpenAI) for powerful responses. You control the privacy and power.
📝 Seamless Integration Works right inside Obsidian, so you never have to switch between apps. Your notes and AI chat live together.
🔒 Privacy-Focused Options Use local models to keep your data on your computer. No internet connection required for local models.
⌨️ Command Palette Support Trigger AI actions with simple commands. Select text and run a command to ask the model anything.
⚙️ Customizable Settings Configure model endpoints and API keys easily through a friendly settings panel. No coding needed.

🖥️ Using the Plugin

After installation, you can access the AI chat in several ways. Each interface is intuitive and designed for non-technical users.

  • Modal Chat: Press a hotkey or use the command palette to open a chat window that appears on top of your notes. Perfect for quick questions.
  • Widget: Keep a small chat widget visible while you work. It stays out of the way but is always ready.
  • FAB Window: Click a floating action button to open a chat window. Great for multitasking.
  • Commands: Type a command like "Ask AI" to send selected text to the model. The response appears in your note or in a chat window.

You can switch between local and web-based models in the plugin settings. The settings panel is user-friendly—just choose your model type and enter any required details. For local models, ensure the model server is running. For web-based models, you will need an API key from the provider.

❓ Troubleshooting

If the plugin does not appear after installation, make sure it is enabled in Obsidian's settings under "Community Plugins." Check that you have the latest version of Obsidian. If you have issues with a local model, ensure the model server is running and the endpoint is correct. For web-based models, verify your API key and internet connection. More help is available on the GitHub issues page, where you can search for similar problems or ask a question.
